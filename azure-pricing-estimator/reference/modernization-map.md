# Modernization map

Authoring verification: **2026-09-16**. Every row's cited product/status evidence was checked during this revision using Microsoft Learn MCP `ms_learn_mcp-microsoft_docs_search` and/or `ms_learn_mcp-microsoft_docs_fetch`. These citations are an evidence-backed starting point, not a permanently valid lifecycle or regional-availability cache. No prices are prescribed here.

## Mandatory runtime gate

- **Verify via Learn = Y:** recheck the exact source product/version/SKU and proposed replacement through the available Learn MCP tools on every invocation. Distinguish a rename, announced retirement, completed retirement, unsupported release, and architecture change. Do not label an entire family retired because one member is retired.
- **Regional check needed = Y:** before any substitution, independently establish that the exact replacement SKU/tier, version, deployment model and required features are supported in the configured region at run time. GA is the default; only explicit request-scoped preview opt-in permits an evidenced preview replacement. A product-family overview, lifecycle notice, retail meter or calculator entry does not establish regional support alone. Apply `availability-gate.md`; do not infer SKU availability from availability of the parent service.
- Record the customer wording, source status, selected replacement, compatibility rationale, Learn URLs, separate GA/regional evidence and verification date. Preserve capacity, engine/API, OS, architecture, networking, HA, licensing and functional requirements; a similar name is not equivalence.
- If regional support, actual release status or compatibility cannot be established, mark the candidate **unverified** and do not substitute or price it as approved. Surface the gap and obtain a decision for a materially different architecture, region or partner. Do not silently use a preview or another region. Preview opt-in does not waive evidence or compatibility.
- For global, SaaS, partner or customer-hosted offerings, first verify the actual location model, availability in the user's approved geography, tenant/data residency, billing geography and supported purchasing/calculator channel. Do not invent a regional SKU for a global product. Apply the configured-region gate separately to regional Azure components.
- “Current family” below means documented current offerings with **no blanket retirement or mandatory substitution**; it does not certify every tier, feature or historic release. This map never expands estimate scope: retain the skill's inclusion and commercial rules.

## Coverage and evidence boundaries

The **45 rows** cover all **26 `serviceFamily` values** documented in the [Retail Prices API taxonomy](https://learn.microsoft.com/en-us/rest/api/cost-management/retail-prices/azure-retail-prices#supported-servicefamily-values) at authoring: Analytics, Azure Arc, Azure Communication Services, Azure Security, Azure Stack, Compute, Containers, Data, Databases, Developer Tools, Dynamics, Gaming, Integration, Internet of Things, Management and Governance, Microsoft Syntex, Mixed Reality, Networking, Other, Power Platform, Quantum Computing, Security, Storage, Telecommunications, Web and Windows Virtual Desktop. AI/ML, search, identity, migration, backup/DR, media and blockchain are additionally explicit.

This is a comprehensive **family index**, not every Azure service, version or SKU. Product overviews establish family/product scope, not universal support or regional GA. For an unlisted service or an exact mapping not established by a row, use the no-match research gate above. If a citation redirects to unrelated content, conflicts with a more specific notice or no longer supports the claim, research a current source and record the uncertainty; never reuse an unverified date or infer a replacement from the old name.
